# 🧠 Памятка: Как пользоваться pre-commit, black, flake8, mypy

---

## 📁 1. При первом запуске (или после клонирования проекта):

```bash
py -3.12 -m pip install --upgrade pip
py -3.12 -m pip install pre-commit flake8 black mypy
```

---

## ⚙️ 2. Установка хуков (нужно один раз на проект):

```bash
py -3.12 -m pre_commit install
```

Создаёт `.git/hooks/pre-commit`, который запускается **перед каждым коммитом**.

---

## 🧪 3. Проверить все файлы вручную:

```bash
py -3.12 -m pre_commit run --all-files
```

Только изменённые файлы:

```bash
py -3.12 -m pre_commit run
```

---

## 🔀 4. Обновить версии хуков:

```bash
py -3.12 -m pre_commit autoupdate
```

---

## 💥 5. Очистить кэш при ошибках:

```bash
py -3.12 -m pre_commit clean
```

---

## 🔎 Быстрые команды для ручной проверки

* Форматировать код по стилю `black`:

```bash
py -3.12 -m black .
```

* Проверка стиля кода с `flake8`:

```bash
py -3.12 -m flake8 .
```

* Статическая проверка типов с `mypy`:

```bash
py -3.12 -m mypy .
```

---

## 📁 Где хранятся настройки

* `.pre-commit-config.yaml` — список хуков (black, flake8, isort, mypy и др.)
* `.flake8` — конфигурация `flake8` (игнорируемые ошибки, длина строки и др.)
* `pyproject.toml` — может использоваться `black` или `isort` для настройки

---

## 🧼 Автоматическая проверка перед коммитом

После `pre_commit install` при каждом коммите выполняется:

* удаление лишних пробелов
* проверка `black`
* сортировка импортов (`isort`)
* анализ кода (`flake8`, `mypy`)
* и любые другие хуки

---
